🔐 Authentication & User Management

Email OTP-verified registration, credential login, password reset workflows, profile management, and sub-admin provisioning.

POST /api/auth/send-register-otp Step 1: Request 6-digit OTP for Registration
PUBLIC

Sends a 6-digit numeric OTP to the specified email address for verification. Alias: /api/auth/send-otp. OTP expires in 10 minutes.

JSON Request Body Schema
FieldTypeRequiredDescription
emailstringRequiredRecipient's valid email address
Request JSON Body 
{
  "email": "player.adelux@example.com"
}
cURL Command 
curl -X POST "http://localhost:5000/api/auth/send-register-otp" \
  -H "Content-Type: application/json" \
  -d '{"email": "player.adelux@example.com"}'
Response Example (200 OK) 
{
  "message": "Verification OTP sent to your email.",
  "email": "player.adelux@example.com"
}
POST /api/auth/register Step 2: Submit Details with OTP to Complete Registration
PUBLIC

Verifies the entered OTP and creates a new user record in the database. Returns JWT auth token and sets an httpOnly cookie. (If OTP is not supplied, it automatically dispatches an OTP).

JSON Request Body Schema
FieldTypeRequiredDescription
namestringOptionalFull name of the user
emailstringRequiredUser email
phonestringOptionalUnique phone number
passwordstringRequiredAccount password (hashed with bcrypt)
membershipstringOptionalGOLD, SILVER, or JUNIOR (default: JUNIOR)
otpstringRequired6-digit code received via email

  "phone": "9876543210",
  "password": "SecurePassword123!",
  "membership": "GOLD",
  "otp": "123456"
}

curl -X POST "http://localhost:5000/api/auth/register" \
  -H "Content-Type: application/json" \
  -d '{"name": "Alex Johnson", "email": "alex.johnson@example.com", "phone": "9876543210", "password": "SecurePassword123!", "membership": "GOLD", "otp": "123456"}'
Response Example (201 Created) 
{
  "message": "User registered and verified successfully",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {

📅 Court Booking Engine

Atomic 3-minute temporary capacity holds, concurrency protection via PostgreSQL SELECT FOR UPDATE, wallet balance deductions, and cancellation refunds.

POST /api/bookings/hold Step 1: Create a 3-Minute Temporary Capacity Hold
MEMBER

Acquires an atomic row lock on the Slot model, verifies capacity against active holds and confirmed bookings, calculates membership discount, and creates a hold with expiresAt = now + 3 mins.

JSON Request Body Schema
FieldTypeRequiredDescription
sportstringRequiredCRICKET, TENNIS, BADMINTON, PADEL_COURT
datestringRequiredBooking date (YYYY-MM-DD)
startTimestringRequiredSlot start time (e.g. 10:00)
playerCountnumberOptionalNumber of players (default: 1)
Request JSON Body 
{
  "sport": "PADEL_COURT",
  "date": "2026-11-22",
  "startTime": "10:00",
  "playerCount": 2
}
cURL Command 
curl -X POST "http://localhost:5000/api/bookings/hold" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -d '{"sport": "PADEL_COURT", "date": "2026-11-22", "startTime": "10:00", "playerCount": 2}'
Response Example (201 Created) 
{
  "message": "Slot held successfully for 3 minutes. Please confirm to finalize booking.",
  "hold": {
    "id": "bkg-hold-uuid-1234",
    "userID": "user-uuid-5678",
    "whichCourt": "PADEL_COURT",
    "slot": "2026-11-22T04:30:00.000Z",
    "endTime": "2026-11-22T05:00:00.000Z",
    "playerCount": 2,
    "basePrice": "1200.00",
    "discountPercentage": "20.00",
    "totalAmount": "960.00",
    "status": "HELD",
    "expiresAt": "2026-11-21T10:33:00.000Z"
  }
}
POST /api/bookings/confirm Step 2: Confirm Booking & Deduct Balance
MEMBER

Validates that the hold has not expired, checks user wallet balance (User.amount >= totalAmount), deducts the booking fee, marks status as CONFIRMED, and broadcasts availability update via Socket.IO.

Request JSON Body 
{
  "holdId": "bkg-hold-uuid-1234"
}
cURL Command 
curl -X POST "http://localhost:5000/api/bookings/confirm" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -d '{"holdId": "bkg-hold-uuid-1234"}'
Response Example (200 OK) 
{
  "message": "Booking confirmed successfully. Payment deducted from membership balance.",
  "booking": {
    "id": "bkg-hold-uuid-1234",
    "status": "CONFIRMED",
    "totalAmount": "960.00"
  },
  "remainingBalance": 4040.00
}
DEL /api/bookings/hold/:id Release Unconfirmed Hold Early
MEMBER

Immediately deletes a held booking so other members can grab the capacity slot without waiting for the 3-minute timer.

curl -X DELETE "http://localhost:5000/api/bookings/hold/bkg-hold-uuid-1234" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"

🔄 Socket.IO Real-Time Availability Room

Live WebSocket subscription for padel and court slots. Emits instant updates when holds are created, confirmed, expired, or cancelled.

WS ws://localhost:5000 (Socket.IO) Client Event Specifications
PUBLIC
Client-to-Server Events
Event NamePayloadDescription
join_sport_room{ "sport": "PADEL_COURT", "date": "2026-11-22" }Join date/court room
leave_sport_room{ "sport": "PADEL_COURT", "date": "2026-11-22" }Leave date/court room
Server-to-Client Broadcasts
Event NamePayloadTrigger
slot_updated{ "sport", "date", "slotTime", "availableSpots" }Hold created, confirmed, or cancelled
JavaScript Client Example 
import { io } from "socket.io-client";

const socket = io("http://localhost:5000", { withCredentials: true });

socket.on("connect", () => {
  console.log("Connected with Socket ID:", socket.id);
  // Join live room for Padel Court on 2026-11-22
  socket.emit("join_sport_room", { sport: "PADEL_COURT", date: "2026-11-22" });
});

socket.on("slot_updated", (data) => {
  console.log("Live Slot Update Received:", data);
  // data: { sport: 'PADEL_COURT', date: '2026-11-22', slotTime: '10:00', available: 5 }
});
